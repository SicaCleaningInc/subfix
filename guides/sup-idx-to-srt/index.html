SUP、IDX/SUB 圖形字幕轉 SRT 教學

更新日期：2026-11-27

從藍光或 DVD 抽出的字幕，很多是 SUP 或 IDX/SUB 格式。它們其實是一張張圖片，不能直接修改，也有不少電視和播放器不支援。要變成 SRT，就要經過文字辨識（OCR）。

想直接解決？ OCR 後一鍵轉繁體，支援香港及台灣用字。

A

需要的工具：Subtitle Edit

Subtitle Edit 是 Windows 上免費、開源的字幕編輯軟件，內建 OCR 功能，支援中文辨識。

B

步驟

  1. 安裝並開啟 Subtitle Edit。
  2. 用「檔案」→「開啟」選擇 .sup，或 DVD 字幕的 .idx（要與同名的 .sub 放在一起）。
  3. Subtitle Edit 會開啟 OCR 視窗。選擇 OCR 引擎及語言：繁體中文或簡體中文。第一次使用時，軟件可能會提示下載語言資料。
  4. 按開始辨識，完成後檢查結果，修正辨識錯誤的字。
  5. 按確定，再用「另存新檔」儲存為 SRT。

Subtitle Edit 的選項名稱和 OCR 引擎會隨版本更新，以實際介面為準。

C

提高辨識準確度

  • 中文 OCR 一定會有錯字，特別是相似的字，例如「己、已、巳」，完成後要逐句檢查。
  • 如果原字幕是簡體，可以先辨識為簡體，再用 簡體轉繁體工具 轉換，比直接辨識繁體更準確。
D

轉成 SRT 之後

  • 確認編碼是 UTF-8：字幕亂碼修復
  • 時間對不上：字幕時間軸調整
  • 要先從影片抽出字幕：MKV 抽出字幕教學
E

疑難排解對照表

看到的情況可能原因怎樣處理
OCR 錯字很多字幕圖片解析度低，或字型較特別改用支援中文的 OCR 方法（例如 Tesseract 加中文語言包），並逐句檢查
IDX/SUB 開不到IDX 與 SUB 必須同名、放在同一資料夾確認兩個檔案名稱一樣，再開啟 .idx
同一個字每次都認錯OCR 字典沒有記住正確寫法手動輸入一次，Subtitle Edit 會加入字典，之後自動套用
轉出的 SRT 中文亂碼儲存時用了舊編碼存檔時選 UTF-8，或用字幕亂碼修復轉換
時間軸與影片對不上SUP 來自另一個影片版本用字幕時間軸調整整體調整

小貼士：OCR 一定會有少量錯字，轉換後建議快速播放一次，留意常見錯誤，例如「己／已」「末／未」。
