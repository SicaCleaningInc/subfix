PotPlayer 字幕亂碼解決方法

更新日期：2026-11-17

PotPlayer 是 Windows 上很受歡迎的播放器，大部分字幕都能直接播放。但遇到舊的 GBK 或 Big5 字幕，偶爾仍會出現亂碼、問號或方格。以下由最簡單的方法開始排查。

想直接解決？ 自動偵測 GBK、Big5 等編碼，一鍵轉為 UTF-8，檔案不會上傳。
使用字幕亂碼修復

方法一：把字幕轉為 UTF-8（最穩陣）

亂碼的根本原因，通常是字幕用了 GBK（簡體）或 Big5（繁體）編碼，而播放器猜錯了。與其逐個播放器調設定，不如直接把字幕檔轉為 UTF-8，之後無論用 PotPlayer、VLC、電視或手機播放都不會再出問題。

用 字幕亂碼修復工具 拖入字幕，工具會自動偵測原本的編碼並轉為 UTF-8，再用新檔取代舊檔即可。

方法二：在 PotPlayer 調整字幕編碼

如果只想臨時看一集，可以在 PotPlayer 內手動指定編碼：

  1. 播放時按 F5 開啟「參數選項」（Preferences）。
  2. 進入「字幕」相關設定，找「字元集」或「文字編碼」選項（不同版本的位置和名稱略有不同）。
  3. 簡體字幕試選「簡體中文（GB2312／GBK）」，繁體字幕試選「繁體中文（Big5）」。
  4. 套用後重新載入字幕。

缺點是設定會影響所有字幕，換另一個編碼的字幕又要再改，所以長遠還是建議用方法一。

方法三：字幕變成方格？檢查字型

如果字幕顯示為「□□□」方格，而不是亂七八糟的怪字，問題多數在字型而不是編碼：目前選用的字型沒有中文字。在 PotPlayer 的字幕字型設定中，改用「Microsoft JhengHei（微軟正黑體）」或「Microsoft YaHei（微軟雅黑）」等中文字型即可。

ASS 特效字幕會自帶指定字型，如果你的電腦沒有安裝該字型，也可能顯示異常。可以把字幕 轉為 SRT，改由播放器的預設字型顯示。

方法四：字幕不出現

  • 確認字幕與影片檔名相同（只有副檔名不同），並放在同一個資料夾。
  • 右鍵 → 字幕，檢查字幕是否被關閉，或選錯了字幕軌。
  • 也可以直接把字幕檔拖進播放視窗載入。
