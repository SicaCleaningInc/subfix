字幕檔名命名規則：讓播放器自動載入字幕

更新日期：2026-11-18

很多「字幕不出現」的問題，原因其實只是檔名不對。播放器靠檔名把字幕配對到影片，只要跟着下面的規則命名，大部分播放器都會自動載入。

A

基本規則：與影片同名

字幕檔名要與影片完全相同，只有副檔名不同，並放在同一個資料夾：

Movie (2024).mkv
Movie (2024).srt

多一個空格、少一個點、全形和半形括號不同，都可能令電視或播放器找不到字幕。最穩陣的做法是複製影片檔名，再貼上作字幕檔名。

B

加上語言標記

在副檔名前加上語言代碼，播放器就會知道這是中文字幕：

Movie (2024).zh.srt
Movie (2024).chi.srt
  • .zh（ISO 639-1）和 .chi 或 .zho（ISO 639-2）是最多軟件支援的中文代碼。
  • 部分軟件可辨認 zh-TW、zh-HK 等地區標記，但並非每個軟件都支援，不確定時用 .zh 最安全。
  • 英文用 .en 或 .eng，日文用 .ja 或 .jpn，韓文用 .ko 或 .kor。
C

同一部影片有多條字幕

Movie (2024).zh.srt
Movie (2024).en.srt
Movie (2024).zh.forced.srt

.forced 用於只翻譯外語對白或畫面文字的「強制字幕」，Plex、Jellyfin 等軟件支援這個標記。

想簡體和繁體各一份？用 簡體轉繁體工具 生成繁體版，工具可以自動在檔名加入語言標記。

D

各播放器的分別

  • 電視、機頂盒：最嚴格，通常只接受完全同名，部分型號不認語言標記。詳見 電視字幕問題。
  • Plex、Jellyfin、Emby：支援語言標記，加入字幕後要重新掃描媒體庫。詳見 Plex、Jellyfin、Emby 中文字幕。
  • Kodi：支援語言標記，亦可在播放時手動選擇字幕。
  • VLC：較寬鬆，檔名開頭與影片相同的字幕一般都會載入。
E

檔名正確仍然不出現？

先檢查字幕格式和編碼。電視一般只支援 SRT 和 UTF-8，可以用 ASS 轉 SRT 及 字幕亂碼修復 處理。

字幕亂碼修復：自動偵測 GBK、Big5 等編碼，一鍵轉為 UTF-8，檔案不會上傳。
