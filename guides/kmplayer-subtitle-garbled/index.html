KMPlayer 字幕亂碼解決方法

更新日期：2026-11-18

KMPlayer 是老牌的 Windows 及手機播放器。遇到舊的 GBK 或 Big5 字幕時，有機會出現亂碼。以下是解決方法。

想直接解決？ 自動偵測 GBK、Big5 等編碼，一鍵轉為 UTF-8，檔案不會上傳。

方法一：把字幕轉為 UTF-8（建議）

用 字幕亂碼修復工具 拖入字幕，自動偵測編碼並轉為 UTF-8，再取代原檔。之後在 KMPlayer 或任何播放器都能正確顯示。

B

方法二：在 KMPlayer 調整編碼

  1. 按 F2 開啟「參數設定」（Preferences）。
  2. 在字幕相關設定中，找語言或編碼選項（不同版本位置略有不同）。
  3. 簡體字幕試選簡體中文（GBK），繁體字幕試選繁體中文（Big5）。
  4. 重新載入字幕。
C

字幕變成方格

方格代表字型沒有中文字。在字幕字型設定中，改用微軟正黑體、微軟雅黑等中文字型。

D

字幕不出現

  • 字幕與影片同名、同一個資料夾，見 字幕檔名命名規則。
  • 也可以直接把字幕檔拖進播放視窗。
E

其他播放器

如果 KMPlayer 問題太多，可以改用 PotPlayer 或 VLC。
