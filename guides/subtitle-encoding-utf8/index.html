B

ANSI 是什麼？

Windows 記事本的「ANSI」並不是一種固定編碼，而是跟隨系統地區：簡體中文 Windows 上等於 GBK，繁體中文 Windows 上等於 Big5。所以同一個「ANSI」字幕，在另一部電腦打開就可能變成亂碼。

C

UTF-8 與 UTF-8 BOM

BOM 是放在檔案最開頭的幾個標記位元組，用來告訴軟件「這是 UTF-8」。

  • 大部分電腦播放器不需要 BOM。
  • 部分電視和舊播放器需要 BOM 才會正確辨認，所以字幕加上 BOM 通常更兼容。
D

為什麼會出現亂碼

例如「你好」用 GBK 儲存，播放器卻當成 UTF-8 讀取，就會顯示成一堆怪字。只要用正確的編碼重新讀取，再存成 UTF-8，就能完全還原。

E

如何轉成 UTF-8

  • 最簡單：用 字幕亂碼修復工具，自動偵測原本編碼並轉為 UTF-8，可一次處理多個檔案。
  • 記事本：如果記事本能正確顯示文字，選「另存新檔」，在「編碼」選 UTF-8 即可。如果記事本打開已經是亂碼，代表它猜錯了，直接另存會令文字永久損壞。
