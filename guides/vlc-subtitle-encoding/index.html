VLC 字幕亂碼設定教學

更新日期：2026-11-14

VLC 是最受歡迎的免費播放器之一，但播放中文字幕時，有時會出現亂碼或方格。這通常與字幕編碼或字型設定有關。以下教你三種解決方法：設定字幕文字編碼、更換支援中文的字型，或直接把字幕轉為 UTF-8（推薦）。

想直接解決？ 一次把字幕轉為 UTF-8，以後在任何播放器都不用再調設定。

A

先判斷是哪一種問題

  • 出現怪字（例如 ÄãºÃ 或 浣犲ソ）：字幕編碼讀錯了，請看方法一或方法三。
  • 出現方格（例如 □□□）：編碼大致正確，但字型不支援中文，請看方法二。
B

方法一：設定字幕文字編碼

VLC 預設會嘗試自動判斷字幕編碼，但遇到 GBK 或 Big5 編碼的字幕時有機會判斷錯誤。可以手動指定：

  1. 打開 VLC，進入「工具」→「偏好設定」（英文介面為 Tools → Preferences）。
  2. 在視窗左下角的「顯示設定」選擇「全部」（All），切換到進階設定。
  3. 在左邊依次展開「輸入／編解碼器」→「字幕編解碼器」→「字幕」（Input / Codecs → Subtitle codecs → Subtitles）。
  4. 找到「字幕文字編碼」（Subtitle text encoding），簡體字幕選「Universal, Chinese (GB18030)」，繁體舊字幕選「Traditional Chinese (Big5)」。
  5. 按「儲存」，然後關閉並重新開啟影片，設定才會生效。

注意：這個設定會套用到所有字幕。如果你同時會播放簡體和繁體字幕，每次都要重新切換，相當麻煩。這時方法三會更方便。

不同版本的 VLC 選單名稱可能略有不同，如果找不到，可以在進階設定頂部的搜尋框輸入「encoding」或「編碼」。

C

方法二：更換支援中文的字型

如果字幕顯示為方格，可以更換字型：

  1. 進入「工具」→「偏好設定」，保持「簡易」顯示設定。
  2. 選擇頂部的「字幕／OSD」（Subtitles / OSD）分頁。
  3. 在「字型」選擇支援中文的字型，例如 Windows 的「Microsoft JhengHei」（微軟正黑體）或「Microsoft YaHei」（微軟雅黑），Mac 的「PingFang TC」。
  4. 按「儲存」，重新開啟影片。
D

方法三：直接把字幕轉為 UTF-8（推薦）

與其每次調整 VLC 設定，不如把字幕檔本身轉為 UTF-8。UTF-8 是國際通用標準，VLC 及絕大部分播放器、電視、手機都能正確讀取，轉換一次就不用再煩惱。

使用 字幕亂碼修復工具，把字幕拖放進去，工具會自動判斷原本的編碼並轉為 UTF-8，檔名維持不變，下載後覆蓋舊檔即可。

E

字幕時間不對？

如果字幕文字正常，但出現時間比對白早或遲，可以在 VLC 播放時按 G 或 H 鍵臨時調整。想永久修正，可以使用 字幕時間軸調整工具。
