A

硬字幕和軟字幕的分別

  • 硬字幕：字幕成為畫面的一部分，不能關掉，但任何播放器都會顯示。
  • 軟字幕：字幕作為獨立軌道放在影片檔內，可以開關，但要播放器支援。
B

燒錄前先準備好字幕

  1. 確認字幕是 UTF-8，否則燒出來會是亂碼：用 字幕亂碼修復 轉換。
  2. 時間軸要對準：用 字幕時間軸調整 修正。
  3. 直式短片一行字不要太長：用 字幕斷句工具 自動斷行。
C

方法一：HandBrake（免費、有圖形介面）

  1. 安裝 HandBrake，開啟影片。
  2. 進入「字幕」（Subtitles）分頁，選擇匯入字幕，載入 SRT 檔。
  3. 匯入時如有「字元編碼」（Character Code）選項，選 UTF-8。
  4. 勾選該字幕的「燒入」（Burn In）。
  5. 設定輸出位置，按開始編碼。
D

方法二：ffmpeg（適合大量處理）

ffmpeg -i video.mp4 -vf "subtitles=sub.srt" -c:a copy output.mp4

如果中文顯示為方格，代表預設字型沒有中文字，可以指定中文字型：

ffmpeg -i video.mp4 -vf "subtitles=sub.srt:force_style='FontName=Noto Sans CJK TC'" -c:a copy output.mp4

字型名稱要換成你電腦上已安裝的中文字型。

E

只想加入軟字幕？

不重新編碼、速度快很多：

ffmpeg -i video.mp4 -i sub.srt -c copy -c:s mov_text output.mp4
F
