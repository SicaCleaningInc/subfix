Windows 媒體播放器載入字幕及亂碼解決方法

更新日期：2026-11-18

Windows 內建的媒體播放器（Media Player）和「電影與電視」都可以播放 SRT 字幕，但不像第三方播放器那樣能調整編碼。以下教你正確載入字幕和解決亂碼。

想直接解決？ 自動偵測 GBK、Big5 等編碼，一鍵轉為 UTF-8，檔案不會上傳。
使用字幕亂碼修復

載入字幕

  • 自動載入：把字幕與影片放在同一個資料夾，並使用相同檔名（只有副檔名不同），見 字幕檔名命名規則。
  • 手動選擇：播放時在字幕或「…」選單中選擇字幕檔（不同版本按鈕位置略有不同）。

中文字幕亂碼

Windows 內建播放器沒有讓你選擇字幕編碼的選項，遇到 GBK 或 Big5 字幕就可能顯示亂碼。

解決方法：用 字幕亂碼修復工具 把字幕轉為 UTF-8，再重新載入。

支援的字幕格式

建議使用 SRT。ASS 等特效字幕的支援有限，可以先用 ASS 轉 SRT 轉換；WebVTT 字幕可以用 VTT 轉 SRT。

更改字幕大小、顏色

Windows 的「設定」→「協助工具」→「字幕」可以調整字幕的字型、大小和顏色，部分內建播放器會跟隨這個設定。

需要更多功能？

想調整字幕延遲或使用 ASS 特效字幕，可以改用 PotPlayer 或 VLC。
