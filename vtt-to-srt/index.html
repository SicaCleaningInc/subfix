VTT 轉 SRT：WebVTT 字幕轉換

把 YouTube、網上課程下載的 WebVTT 字幕轉為通用的 SRT 格式，電視、播放器、剪片軟件都能讀取。可批量處理。

🔒 檔案只在你的瀏覽器內處理，不會上傳

使用方法

  1. 選擇 VTT 字幕：把 .vtt 檔案拖放到方框內，YouTube 舊式的 .sbv 字幕也可以。
  2. 檢查預覽：確認轉換後的時間碼和對白正確。
  3. 下載 SRT：檔名會保留原本名稱，只把副檔名改為 .srt。整批字幕可以打包成 ZIP。

VTT 和 SRT 有什麼不同？

兩者寫法相似，但有幾個關鍵分別，令不少播放器讀不到 VTT：

VTTSRT
檔案開頭必須有 WEBVTT沒有標頭
序號可有可無每句都有
毫秒分隔句號 00:01.000逗號 00:00:01,000
小時可以省略必須寫出
額外設定位置、講者、顏色標籤只有簡單格式

轉換時會處理什麼？

  • 移除 WEBVTT 標頭，以及 NOTE、STYLE 等區塊。
  • 移除時間碼後的位置設定，例如 align:start position:10%。
  • 移除講者 <v 名字>、顏色 <c.yellow> 及逐字時間標籤。
  • 把 &amp; 等 HTML 符號還原為正常字元。
  • 補上序號，並把時間碼轉為 SRT 格式。

常見問題

為什麼電視讀不到 VTT 字幕？

不少電視和舊播放器只支援 SRT。VTT 的標頭、時間碼寫法和額外標籤都可能令它們無法辨認，轉為 SRT 後通常就能正常顯示。

轉換後字幕的位置設定會保留嗎？

不會。SRT 不支援 VTT 的位置設定，轉換時會移除，字幕會顯示在播放器預設位置，通常是畫面底部。

字幕檔案會上傳到伺服器嗎？

不會。所有處理都在你的瀏覽器內完成，字幕檔案不會離開你的電腦或手機。

可以把 SRT 轉回 VTT 嗎？

目前本工具只支援轉為 SRT。由於 SRT 的兼容性最高，一般情況下建議使用 SRT。
