日文、韓文字幕亂碼修復

日劇、動畫或韓劇字幕變成一堆符號？把檔案拖放到下面，自動偵測 Shift-JIS、EUC-KR 等編碼並轉為 UTF-8，在任何裝置都能正常顯示。

🔒 檔案只在你的瀏覽器內處理，不會上傳

使用方法

  1. 選擇字幕檔案：把出現亂碼的日文或韓文字幕拖放到上方方框，可以一次選擇整季。
  2. 確認預覽：每個檔案旁邊會顯示偵測到的編碼，以及頭幾句對白。文字正常就代表修復成功。
  3. 下載：檔名維持不變，直接覆蓋舊檔即可，播放器會自動配對影片。

日文、韓文字幕為甚麼會變亂碼？

舊的日文字幕大多以 Shift-JIS 儲存，舊的韓文字幕則多數是 EUC-KR（或 Windows 的擴充版 CP949）。智能電視、手機及很多網頁播放器預期 UTF-8，用錯誤的規則去讀取，就會顯示一堆怪字。字幕內容其實沒有損壞，只要轉換成 UTF-8 就能還原。

改用 VLC 設定也可以

進入「工具」→「偏好設定」，左下角選「全部」，打開「輸入／編解碼器」→「字幕編解碼器」→「字幕」，把「字幕文字編碼」改為 Japanese (Shift-JIS) 或 Korean (EUC-KR/CP949)，儲存後重新開啟影片。這個設定會影響所有字幕，所以一般直接轉換檔案會方便得多。

常見問題

可以自動偵測哪些編碼？

UTF-8、UTF-16、日文 Shift-JIS（包括 Windows CP932）、韓文 EUC-KR／CP949，以及中文 GBK 和 Big5。如果偵測錯了，可以在檔案下方的選單改選其他編碼，預覽會即時更新。

字幕檔案會上傳到伺服器嗎？

不會。所有處理都在你的瀏覽器內完成，字幕檔案不會離開你的電腦或手機。

修復後的字幕會改變檔名嗎？

不會。下載的檔案保留原本檔名，播放器仍可自動配對同名影片。

EUC-JP、ISO-2022-JP 的檔案可以嗎？

這兩種舊式日文編碼在字幕檔案中很少見，暫時不會自動偵測。絕大部分日文字幕都是 Shift-JIS 或 UTF-8。

修復後顯示方格，看不到日文或韓文？

編碼已經正確，但播放器使用的字型沒有日文或韓文字。請在播放器設定中選擇支援的字型，例如日文用 Meiryo 或 Yu Gothic，韓文用 Malgun Gothic。
