Hong Kong vs Taiwan: what changes?

Traditional Chinese differs between regions in two ways: some character forms, and everyday vocabulary. The Hong Kong option changes character forms only; the Taiwan vocabulary option also swaps mainland terms for Taiwanese ones:

Safe for ASS fansub files

ASS subtitles contain style definitions and font names as well as dialogue. If a converter changes the font name 微软雅黑 into 微軟雅黑, the player can no longer find the font. This tool only converts the dialogue field of each line and leaves everything else exactly as it was.

FAQ

What is the difference between Hong Kong and Taiwan Traditional Chinese?

Some characters are written differently — Hong Kong often uses 裏 and 着, while Taiwan uses 裡 and 著. The Taiwan option can also convert vocabulary, for example 软件 (software) becomes 軟體 and 视频 (video) becomes 影片.

Are my files uploaded?

No. Conversion happens entirely in your browser.

Will ASS fonts and effects break?

No. Only the dialogue text is converted. Style definitions, font names and override tags in curly braces are left untouched, so your player can still find the fonts.

Can it handle garbled subtitles?

Yes. The tool detects GBK, Big5 and UTF-8 first, then converts. Output is always UTF-8.

Why not just convert character by character?

Many Simplified characters map to several Traditional ones depending on context — 发 is 髮 in 头发 (hair) but 發 in 发现 (discover). OpenCC matches whole words first, which handles these cases far better.
