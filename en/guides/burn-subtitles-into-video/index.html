How to Burn Subtitles Into a Video (Hardsubs)

Updated: 2026-11-20

Some devices and platforms can't show external subtitles. Burning them into the picture ("hardsubs") makes them visible everywhere.

Hardsubs vs softsubs

  • Hardsubs are part of the picture: always visible, can't be turned off.
  • Softsubs are a separate track in the file: can be toggled, but the player must support them.
B

Prepare the subtitle first

  1. Make sure it's UTF-8, or the burned text will be garbled: Garbled Subtitle Fixer.
  2. Get the timing right: Subtitle Time Shift.
  3. For vertical video, keep lines short: line-break tool (Chinese interface).
C

Method 1: HandBrake (free, graphical)

  1. Install HandBrake and open the video.
  2. Go to the Subtitles tab and import the SRT file.
  3. If there is a Character Code option, choose UTF-8.
  4. Tick Burn In for that subtitle.
  5. Choose where to save and start encoding.
D

Method 2: ffmpeg (great for batches)

ffmpeg -i video.mp4 -vf "subtitles=sub.srt" -c:a copy output.mp4

If Chinese shows as boxes, the default font lacks Chinese characters. Name a Chinese font you have installed:

ffmpeg -i video.mp4 -vf "subtitles=sub.srt:force_style='FontName=Noto Sans CJK TC'" -c:a copy output.mp4
E

Just want softsubs?

No re-encoding, much faster:

ffmpeg -i video.mp4 -i sub.srt -c copy -c:s mov_text output.mp4
F

Bilingual hardsubs

Combine Chinese and English with the bilingual subtitle merger first, then burn the merged file.

FAQ

Does burning subtitles reduce video quality?

It requires re-encoding, which can lose a little quality. Use a high quality setting in HandBrake to keep it unnoticeable.

How long does it take?

Roughly as long as any re-encode: often a few minutes to real time depending on your computer and settings.

Can I remove burned-in subtitles later?

No. Keep your original video if you might need a clean copy.
