Convert SUP and IDX/SUB Image Subtitles to SRT

Updated: 2026-11-20

Subtitles ripped from Blu-ray or DVD are often SUP or IDX/SUB files: a series of images, not text. Many TVs don't support them, and you can't edit them. OCR (text recognition) turns them into SRT.

The tool: Subtitle Edit

Subtitle Edit is a free, open-source subtitle editor for Windows with built-in OCR, including Chinese.

B

Steps

  1. Install and open Subtitle Edit.
  2. Use File → Open and choose the .sup file, or the DVD .idx (keep the matching .sub next to it).
  3. The OCR window opens. Pick an OCR engine and language: Traditional or Simplified Chinese. You may be prompted to download language data the first time.
  4. Start OCR, then review the result and correct misread characters.
  5. Click OK and save as SRT.

Option names and OCR engines change between versions; follow what your version shows.

C

Better accuracy

  • Chinese OCR always makes some mistakes, especially with look-alike characters, so proofread line by line.
  • If the source is Simplified, OCR it as Simplified, then convert with the Simplified to Traditional converter. That is usually more accurate than recognising Traditional directly.

FAQ

Is there a Mac version of Subtitle Edit?

Subtitle Edit is built for Windows. Mac users typically run it through Wine or a Windows virtual machine, or use other OCR tools.

Why are some characters wrong after OCR?

OCR guesses from image shapes. Small fonts, outlines and similar-looking characters cause errors. Proofreading is always needed.

Can I keep the original positions and colours?

No. SRT is plain text, so styling from the images is not kept.
