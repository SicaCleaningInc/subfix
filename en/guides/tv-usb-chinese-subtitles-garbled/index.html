TV Subtitles Garbled or Not Showing From a USB Drive: 5 Causes and Fixes

Updated: 2026-11-20

A subtitle that plays perfectly on your computer can turn into gibberish, boxes or nothing at all on a TV. TVs are much stricter than desktop players. Work through these five causes in order.

Cause 1: The subtitle is not UTF-8

This is the most common reason for garbled text. Many older subtitles are saved as GBK (Simplified Chinese) or Big5 (Traditional Chinese). Computer players usually detect them, but most TVs only understand UTF-8, and some older models also need a BOM at the start of the file.

Fix: convert the file with the Garbled Subtitle Fixer and keep "add BOM" ticked. The file name stays the same, so you can overwrite the old file on the USB drive.

B

Cause 2: The file name doesn't match the video

TVs pair subtitles with videos by file name. The subtitle must have exactly the same name as the video, with only the extension changed: Movie.2024.mp4 needs Movie.2024.srt. One extra space or a missing dot is enough for the TV to miss it.

Some TVs accept a language tag such as Movie.2024.zh.srt, but not all. If the subtitle doesn't appear, try the exact video name first. See subtitle file naming rules.

C

Cause 3: The TV doesn't support the format

SRT is supported by almost every TV. ASS and SSA styled subtitles often aren't, or only show plain text. VTT support varies by model.

Fix: convert with ASS to SRT or VTT to SRT. More on formats: SRT vs ASS vs VTT.

D

Cause 4: The subtitle is in a different folder

Most TVs only look for subtitles in the same folder as the video. A subtitle in a "Subs" subfolder is usually ignored, so move it next to the video.

E

Cause 5: Boxes instead of characters

Boxes "□□□" rather than random symbols usually mean the encoding is right but the TV's built-in font lacks some Chinese characters. This is more common on TVs bought outside Asia. Try switching the subtitle font or system language; if there is no such option, cast from a phone or use a media player app instead.

FAQ

Why does the same subtitle work on my computer but not my TV?

Desktop players such as VLC guess the encoding and support many formats. TV players usually expect UTF-8 SRT files with exactly matching names, so anything else fails.

Do I need the BOM option?

It does no harm and helps older TVs recognise UTF-8, so keep it on for TV playback.

Can I keep both Chinese and English subtitles on the USB drive?

Yes. Name them Movie.zh.srt and Movie.en.srt if your TV supports language tags. If you want both on screen at once, use the bilingual subtitle merger.
