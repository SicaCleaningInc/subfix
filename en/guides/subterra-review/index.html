What is Subterra?

Subterra is a subtitle add-on for Kodi. It takes a video's existing subtitle track and translates it on the fly into the language you choose. The developer lists support for more than 50 languages, including Traditional Chinese, Simplified Chinese, Japanese, Korean and English.

That solves a common problem for our readers: a Japanese drama or Korean show with only English subtitles, when you want to watch in Chinese.

How to install Subterra

Subterra is not in the official Kodi repository yet, so it is installed from the developer's own source. Follow the official guide and video on getsubterra.tv. The process follows the usual steps for third-party Kodi add-ons:

  1. In Kodi, open Settings → System → Add-ons and allow installation from unknown sources.
  2. Add Subterra using the source or file linked on the official site.
  3. Open the add-on settings and choose your target language, e.g. Chinese (Traditional).
  4. Play a video that has subtitles; Subterra translates them automatically.

Tips for Chinese, Japanese and Korean

  • Pick the right Chinese: choose Traditional for Taiwan and Hong Kong, Simplified for mainland China and Singapore.
  • Start from a clean source: if the original subtitle is garbled, fix the encoding first with the Garbled Subtitle Fixer (or the Japanese & Korean fixer).
  • Chinese shows boxes in Kodi? That is a font issue, not a translation issue. Set the Kodi font to Arial based: see our Kodi Chinese subtitles guide.
  • Want a permanent file instead? Our Simplified to Traditional converter turns an existing Chinese subtitle file into the other script.
