How to Fix Chinese Subtitles in Kodi (Boxes or Garbled Text)

Updated: 2026-11-18

Kodi's default skin font has no Chinese characters, so many people see rows of boxes the first time they play a Chinese subtitle. Two settings plus correctly encoded files fix it.

Quick fix: Auto-detects GBK, Big5, Shift-JIS and EUC-KR and converts to UTF-8. Files never leave your device.
Open Garbled Subtitle Fixer

Step 1: Switch the font to "Arial based"

This fixes the boxes:

  1. Go to Settings → Interface → Skin.
  2. Change Fonts to Arial based.
  3. The interface reloads, and Chinese text in menus and subtitles can now be displayed.

You can fine-tune the subtitle font itself under Settings → Player → Language → Subtitles (names may differ slightly between versions).

Step 2: Set the subtitle character set

This fixes garbled text. Under Settings → Player → Language, set the subtitle Character set to Chinese Simplified (GBK) or Chinese Traditional (Big5).

It is a global setting, so if you have both Simplified and Traditional files in legacy encodings, one of them will still break.

Step 3 (recommended): Convert all subtitles to UTF-8

UTF-8 subtitles ignore the character set setting and display Simplified, Traditional, Japanese and Korean correctly. Drop several files at once into the Garbled Subtitle Fixer, download them as a ZIP, and replace the originals.
