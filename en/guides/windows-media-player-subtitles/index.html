Windows Media Player: Load Subtitles and Fix Garbled Text

Updated: 2026-11-27

The built-in Windows Media Player and Movies & TV app can play SRT subtitles, but unlike third-party players they don't let you choose the encoding. Here's how to load subtitles and fix garbled text.

A

Loading subtitles

  • Automatically: put the subtitle in the same folder with the same name as the video. See naming rules.
  • Manually: during playback, choose the subtitle file from the subtitles or "…" menu (button positions vary between versions).
B

Garbled Chinese subtitles

The built-in players have no encoding option, so GBK or Big5 subtitles may show up garbled.

Fix: convert the file with the Garbled Subtitle Fixer and load it again.

C

Supported formats

Use SRT. Styled ASS has limited support: convert with ASS to SRT. WebVTT: use VTT to SRT.

D

Change subtitle size and colour

Windows Settings → Accessibility → Captions lets you change caption font, size and colour; some built-in players follow these settings.

E

Need more control?

For subtitle delay or ASS styling, use PotPlayer or VLC. No install allowed? The online subtitle player runs in your browser.

?

FAQ

Does Windows Media Player support SRT?

Yes. The Windows 11 Media Player loads SRT files that sit next to the video with the same name.

Can I adjust subtitle delay in Windows Media Player?

The built-in player has very limited options. Fix the file with the Subtitle Time Shift tool instead.

Why do Chinese characters show as boxes?

The caption font may lack Chinese characters. Choose a different font in Windows caption settings, or use VLC or PotPlayer.
