How to Fix Garbled Chinese Subtitles in PotPlayer

Updated: 2026-11-18

PotPlayer plays most subtitles out of the box, but older GBK or Big5 Chinese subtitles can still show up as gibberish, question marks or boxes. Start with the simplest fix.

Open Garbled Subtitle Fixer

Fix 1: Convert the subtitle to UTF-8 (most reliable)

Garbled text almost always means the file is saved as GBK (Simplified Chinese) or Big5 (Traditional Chinese) and the player guessed the wrong encoding. Converting the file to UTF-8 fixes it for PotPlayer, VLC, TVs and phones alike.

Drop the file into the Garbled Subtitle Fixer. It detects the original encoding and converts it to UTF-8; replace the old file with the new one.

Fix 2: Change the encoding in PotPlayer

  1. Press F5 during playback to open Preferences.
  2. Go to the subtitle settings and look for a character set or text encoding option (the exact location varies between versions).
  3. Try Chinese Simplified (GB2312/GBK) for Simplified subtitles, or Chinese Traditional (Big5) for Traditional ones.
  4. Apply and reload the subtitle.

This setting applies to every subtitle, so you may need to switch it again for the next file. Fix 1 avoids that.

Fix 3: Boxes instead of characters? Check the font

If you see "□□□" rather than random symbols, the encoding is fine but the font has no Chinese characters. Pick a Chinese font such as Microsoft JhengHei or Microsoft YaHei in PotPlayer's subtitle font settings.

ASS subtitles specify their own fonts. If those fonts are not installed, convert the file to SRT so the player's default font is used.

Subtitle not showing at all

  • Give the subtitle the same file name as the video (only the extension differs) and keep both in the same folder.
  • Right-click → Subtitles and check that subtitles are enabled and the right track is selected.
  • You can also drag the subtitle file onto the player window.
