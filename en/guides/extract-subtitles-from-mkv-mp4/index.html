How to Extract Embedded Subtitles From MKV or MP4

Updated: 2026-11-20

MKV files often contain several subtitle tracks. Extract one and you can fix its encoding, convert Chinese, adjust timing or combine it with another language.

A

First: text or image subtitles?

  • Text subtitles (SRT, ASS, SSA, WebVTT) can be edited right after extraction.
  • Image subtitles (Blu-ray PGS/SUP, DVD VobSub) are pictures and need OCR to become SRT. See image subtitles to SRT.
B

Method 1: MKVToolNix (MKV)

MKVToolNix is a free, open-source MKV toolkit for Windows, Mac and Linux.

  1. Install MKVToolNix.
  2. List the tracks and their IDs: 
    mkvmerge -i movie.mkv
  3. If the subtitle is track 2, extract it: 
    mkvextract movie.mkv tracks 2:movie.zh.srt
    Use .ass as the extension if the track is ASS.

Prefer clicking? Graphical front ends built on MKVToolNix, such as gMKVExtractGUI, let you tick the tracks to extract.

C

Method 2: ffmpeg (MKV and MP4)

ffmpeg -i movie.mkv -map 0:s:0 movie.zh.srt

0:s:0 is the first subtitle track, 0:s:1 the second, and so on. ffmpeg converts text subtitles to the format you name.

FAQ

How do I know which track is Chinese?

mkvmerge -i (or ffprobe) lists each track with its language tag, such as chi or zh. Untagged tracks may need a quick test extraction.

ffmpeg says the subtitle codec is not supported for SRT. Why?

The track is probably image-based (PGS or VobSub). Those need OCR; see the image subtitles guide.

Does extracting change the video?

No. Extraction only reads the file and writes a separate subtitle file.
