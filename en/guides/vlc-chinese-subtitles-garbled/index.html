How to Fix Garbled Chinese Subtitles in VLC

Updated: 2026-11-20

VLC plays almost anything, but older Chinese subtitles can still come out as gibberish or boxes. First work out which problem you have, then pick the matching fix.

Fix 1: Set the subtitle text encoding

  1. Open Tools → Preferences.
  2. Under "Show settings" at the bottom left, choose All.
  3. Expand Input / Codecs → Subtitle codecs → Subtitles.
  4. Set "Subtitle text encoding" to Universal, Chinese (GB18030) for Simplified Chinese, or Traditional Chinese (Big5) for older Traditional files.
  5. Click Save, then close and reopen the video.

This applies to every subtitle, so you'll have to switch it back and forth between Simplified and Traditional files. Fix 3 avoids that. Menu names vary slightly between versions; use the search box in the advanced settings and type "encoding".

B

Fix 2: Use a font that supports Chinese

  1. Open Tools → Preferences and keep "Simple" settings.
  2. Open the Subtitles / OSD tab.
  3. Choose a Chinese font, e.g. Microsoft JhengHei or Microsoft YaHei on Windows, PingFang TC on Mac.
  4. Save and reopen the video.
C

Fix 3: Convert the subtitle to UTF-8 (recommended)

Rather than changing VLC settings each time, convert the file itself. UTF-8 works in VLC and nearly every player, TV and phone. Drop the file into the Garbled Subtitle Fixer; it detects the original encoding and keeps the file name.

Timing is off?

Press G or H during playback to nudge subtitles by 50 ms. To fix the file permanently, use the Subtitle Time Shift tool.

FAQ

Why doesn't VLC detect the encoding automatically?

VLC does try, but short files and similar byte patterns make GBK, Big5 and other encodings easy to confuse.

Does VLC for iPhone or Android have the same setting?

Yes. VLC for Mobile has a Text Encoding option under Subtitles in its settings. See phone subtitles guide.

Japanese or Korean subtitles are garbled too. Same fix?

Yes. Use the Japanese & Korean fixer to convert Shift-JIS or EUC-KR files to UTF-8.
