Subtitle File Naming: Make Players Load Subtitles Automatically

Updated: 2026-11-20

Many "subtitle not showing" problems come down to the file name. Players match subtitles to videos by name, so follow these rules and most will load them automatically.

A

Rule 1: Same name as the video

The subtitle must have exactly the same name as the video, only a different extension, in the same folder:

Movie (2024).mkv
Movie (2024).srt

An extra space, a missing dot or different brackets can stop a TV from finding it. The safest way: copy the video's file name and paste it as the subtitle's name.

B

Rule 2: Add a language tag

Movie (2024).zh.srt
Movie (2024).chi.srt
  • .zh (ISO 639-1) and .chi or .zho (ISO 639-2) are the most widely recognised Chinese codes.
  • Some software recognises region tags like zh-TW or zh-HK, but not all. When in doubt, use .zh.
  • English: .en / .eng; Japanese: .ja / .jpn; Korean: .ko / .kor.
C

Multiple subtitles for one video

Movie (2024).zh.srt
Movie (2024).en.srt
Movie (2024).zh.forced.srt

.forced marks "forced" subtitles that only translate foreign dialogue or on-screen text; Plex and Jellyfin support it. Want both Simplified and Traditional? Create the second with the Simplified to Traditional converter.

D

How players differ

  • TVs and set-top boxes: strictest. Usually exact name only; some ignore language tags. See TV subtitle problems.
  • Plex, Jellyfin, Emby: support language tags; rescan the library after adding files. See Plex, Jellyfin & Emby.
  • Kodi: supports language tags, and you can also pick a subtitle manually.
  • VLC: more forgiving; subtitles whose names start with the video name usually load.
E

Name is right but still nothing?

Check the format and encoding. TVs usually need SRT in UTF-8: use ASS to SRT and the Garbled Subtitle Fixer.

FAQ

Should I use .zh or .chi?

Both are widely recognised. .zh is shorter and works in Plex, Jellyfin, Kodi and most players.

Do capital letters matter?

On many TVs and Linux-based devices, yes. Match the video name exactly, including case.

Can subtitles go in a Subs folder?

Plex and Jellyfin can find them there, but TVs usually can't. Keep them next to the video for best compatibility.
